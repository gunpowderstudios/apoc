# APOC – pre-APOC test table
Browser test build of the APOC board game (Gunpowder Studios). Static site, no build step.

- Open `index.html` via any static host (GitHub Pages) or `python3 -m http.server`.
- 1–4 players: any mix of local humans, AI bots, and online players (host opens a room; others join with the code).
- 2D click-to-move board plus a moveable 3D table view. Graph button = overlay/edit the movement graph.
- Rules live in `src/engine.js` (pure, seeded, JSON state). `node tools/sim.mjs 5 4` runs AI-only headless games.
- Data: `data/*.json`; board graph is generated by `tools/build_board.py` (or edit in the browser and export).
- See `ASSUMPTIONS.md` for everything I guessed.
